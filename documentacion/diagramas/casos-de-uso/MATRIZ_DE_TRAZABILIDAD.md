# MATRIZ DE TRAZABILIDAD OBLIGATORIA
## SISTEMA DE GESTIÓN INTEGRAL "PUJOL E HIJOS S.R.L."
**Distribuidora Mayorista de Bebidas (No Alcohólicas) — Formosa, Argentina**

---

### NOTAS DE LECTURA Y RIGOR ACADÉMICO PARA EL TRIBUNAL:

1. **Estructura Arquitectónica:**
   - **Frontend:** Angular 16+ en `admin_metronic_8.2/src/app/`
   - **Backend:** PHP Nativo con PDO bajo patrón Front Controller en `api/index.php`
   - **Base de Datos:** MySQL `pujol_e_hijos` en `bdPujolScript.sql`
2. **Clasificación de Origen de Componentes:**
   - **[A] Desarrollado por nosotros:** Código propio programado por el equipo para Pujol e Hijos S.R.L.
   - **[B] Proporcionado por Framework / Plantilla:** Librerías base de Angular Core/Router o utilidades de Metronic.
   - **[C] Sistema / Servicio Externo:** Proveedor externo independiente (ej. Google OAuth 2.0 UserInfo API).
3. **Aclaración sobre Laravel y Controladores:**
   - El sistema **no utiliza Laravel**. Los despachadores REST en `api/index.php` actúan como controladores de backend recibiendo `$route` y `$method`.
   - Se incluye además la columna con la **equivalencia en convención Laravel MVC** para responder inmediatamente a cualquier analogía exigida por la cátedra.
